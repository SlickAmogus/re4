## Findings
- AX type 1 = stream: on loop wrap the ADPCM history is NOT reloaded (Dolphin AXVoice is_stream); str2:292/302 sets type 1 for the ring wrap, type 0 + AXSetVoiceLoop(0) at stream end (str2:239-267). (CT-06 assumed reload.)
- Aux buffers are 160 s32 per channel (cb_efx_clear_bass clears 0x280 bytes, snd_efx.cpp:209) -> internal mix stays 32 kHz, 160-sample frames.
- AXFX*Init returns 1 on success (snd_efx.cpp:140); param for every effect = &efx->rev_hi (union) -> AXFX side state keyed by struct pointer.
- OS threads are cooperative fibers on one kernel thread, OSDisableInterrupts trivial (os_thread.cpp:16) -> no locking in the pump.
- Xbox DS objects only linked with make RE4_AUDIO_RXDK=1 (xbox/Makefile:62) -> DS sink guarded by RE4_AUDIO_RXDK, else null sink.
- Game SDK surface (grep src/): AX* (Init/Quit/Acquire/Free/SetVoice*: Type Addr Adpcm AdpcmLoop LoopAddr EndAddr Loop Lpf LpfCoefs Src SrcType SrcRatio State Priority; RegisterCallback/AuxA/AuxB; SetMode; SetCompressor (decl include/snd_sdk.h:41); GetDspCycles/GetMaxDspCycles), MIX* (Init Quit InitChannel ReleaseChannel SetInput Pan SPan AuxA AuxB UpdateSettings SetSoundMode), AXFX* Init/Settings/Shutdown x {ReverbHi, ReverbHiDpl2, ReverbStd, Chorus, Delay} + *Callback passed as aux cb, AXFXSetHooks (snd.cpp:192, snd_sdk.h:48), AXART Init/Quit/ServiceSounds, SYN Init Quit InitSynth QuitSynth MidiInput SetMasterVolume GetActiveNotes RunAudioFrame, SEQ Init Quit RunAudioFrame, AIInit(NULL)/AIReset.
- Direct AXVPB pokes: pb.state (iss2:145, iss4:72/211/263, str1:108, str3:278/285 -> game polls state==0 for end of one-shot), pb.addr.loopFlag (iss2:148), `*(u32*)&pb.addr.currentAddressHi` / endAddressHi (iss2:149-150, str2:164). On little-endian a u32 read of Hi/Lo gives (Lo<<16)|Hi -> DECISION: the shim mirrors current/end/loop address into the pb as a native u32 stored at &...AddressHi (Hi field holds low half). Game never reads the pb Hi/Lo halves individually (it only writes its own local AXPBADDR passed to AXSetVoiceAddr, which the shim reads as Hi<<16|Lo).
- AXVPB layout kept exactly (include/dolphin/ax.h); the shim's real voice state lives in a side table indexed by AXVPB::index.
- cb_audio_frame (snd_main.cpp:81) calls Snd_iss_manager, Snd_stream_player, Snd_midi_sequencer (game's own MIDI parser), SEQRunAudioFrame, SYNRunAudioFrame, AXARTServiceSounds, MIXUpdateSettings. Uses OSEnable/RestoreInterrupts -> run the pump on the game thread (no extra thread, no locks).
- SYN: game feeds 3-byte MIDI via SYNMidiInput (seq1:93, seq2:152/158, seq3:96/110); closes a sequence when SYNGetActiveNotes()==0 (seq3:60) -> a stub returning 0 is tolerated. Game never reads SYNSYNTH fields. SYNInitSynth(&seq->synth, wt_adrs, pcm_adrs, zero_adrs, 30,30,1) (seq3:149); wavetable = WTFILEHEADER (include/snd_drv.h:104), same tables iss3 reads natively (iss3:98 iss_ax_set_wt_ptr).
- iss3 one-shot: loopFlag=0, loop addr = zero buffer; real AX sets pb.state=0 at end of non-looped voice -> shim does the same.
- Xbox sink: copy jfduke3d driver_dsound_xbox.c (APU reset regs, g_DirectSoundCriticalSection init, DirectSoundCreate, DSMIXBINS FL/FR, Lock/Unlock ring, DirectSoundDoWork each pump).
