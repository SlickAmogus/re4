# CT-01 — File table vs retail disc audit

**Status:** open

## Goal

Know exactly which files the game asks for and whether the retail USA discs have them, so the DVD shim's
name resolution is right and the asset converter's manifest is complete.

## Inputs (in repo)

- `src/game/dvd.cpp`: `FileTblEntry FileTbl[]` (the indexed table) and every `DvdReadN(name...)` /
  `sprintf(name, "st%x/r%03x_%02x.dat", ...)`-style dynamic name in `src/game/*.cpp`, `src/st*/`,
  `src/Sscrn/`, `src/game/sofdec.cpp`, `src/game/snd*.cpp`, `src/game/card.cpp`, `src/game/read.cpp`,
  `src/game/block.cpp`, `src/game/datactrl.cpp`, `src/game/event.cpp`, `src/game/mes.cpp`.
- `xbox/tools/retail_filelist.txt`: the full file list of both retail discs (paths + sizes), generated
  with `dtk vfs ls` (committed, it is just names).

## Deliverables

1. `xbox/tools/filelist_check.py`: parses `FileTbl[]` and the dynamic patterns (list them by hand in a
   table in the script with the source line), expands patterns against `retail_filelist.txt`, prints:
   files requested but absent on retail, files on retail never requested, name-case mismatches
   (`St1` vs `st1`, `Rel` vs `rel`), and files present only on disc 2.
2. `xbox/docs/04-DATA.md` section "File resolution": the answer to the `.das` vs `.drs` question — the
   debug `FileTbl` names `em/em10.das` while the discs have `em/em10.drs`. Find the mechanism (search for
   `drs`, extension rewriting, `DVDConvertPathToEntrynum` failure handling, `SizeTbl.dat`, `read.cpp`
   enemy loading path; check whether the debug disc had `.das` too via `config/G4BE08/config.yml` which
   says `files/em/<name>.drs`).
3. A `xbox/port/dvd/filenames.inc` (generated by the script) mapping every requested name to its exact
   retail path and disc, used by the DVD shim.

## Acceptance

- Script runs with `python3 xbox/tools/filelist_check.py` and exits 0 with a report.
- Every entry of `FileTbl[]` resolves to a retail path or is listed as "debug-only" with a reason.
- The `.das/.drs` mechanism is documented with the code reference.
