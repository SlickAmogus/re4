# CT-03 — Host build bring-up: preprocessor, static modules, link

**Status:** open · depends on CT-02

## Goal

`make -C xbox -f Makefile.host` compiles every non-debug game unit plus the needed `src/lib` units for
32-bit x86 Linux with clang, links against the stub platform layer in `xbox/port/`, and the resulting
`re4_host` starts, runs the game's `systemStartInit` and stops at the first unimplemented SDK call with a
clear message. This is milestone M1.

## Steps

1. **Unit list** `xbox/units.mk`: enumerate explicitly. Game: all of `src/game/*.cpp|*.c` except the debug
   units (`db_cam db_log db_menu db_work dbmodule debug t_bugcheck t_flag t_log t_option t_page t_prim
   t_sc_shot t_util exception` — check each; some are referenced by game code and may need to stay with
   their drawing stubbed). Modules: `src/Sscrn`, `src/em*`, `src/pl*`, `src/wep*`, `src/st*`, `src/st`
   (shared), each module directory with `-D_prolog=<mod>_prolog -D_epilog=<mod>_epilog
   -D_unresolved=<mod>_unresolved`. Lib: `src/lib` matrix/vector/quat C sources, fdlibm (`sf_*`, `ef_*`,
   `kf_*`), `OSAlloc.c` if usable, the CRI stack (CT-07 may defer it: stub `sofdec.cpp`'s entry points
   first). Exclude `src/Tools`, `src/tools`, `src/t_*`.
2. **Preprocessor** `xbox/tools/prep.py` (`prep.py <src> <out> [--module NAME]`): strips
   `asm("rN")`/`asm("fN")` from declarations, replaces the known asm bodies with `#include`s of the CT-02
   C versions, keeps `#line`. Driven from the Makefile into `xbox/build/prep/<same path>.cpp` with
   dependency tracking.
3. **Force-included header** `xbox/port/include/re4port/re4_xbox.h`: `RE4_PORT`, SDK types, `GC_ADDR`,
   `VALID_PTR`, `main → re4_main`, OSReport → `re4_log`, etc. Extend the skeleton that exists.
4. **Compile**: fix errors by category (see `07-COMPILER.md`). Record each category and its fix in
   `xbox/docs/07-COMPILER.md` under "Observed".
5. **Module table** `xbox/port/os/module_table.cpp`: generated by `xbox/tools/gen_module_table.py` from the
   module directories; `DLL_Link`/`DLL_Unlink` replaced via macro to `re4_module_link(OSModuleHeader*)`
   that finds the module by the archive name the caller loaded (see `read.cpp` 461–505, 695, 956 and
   `main_sub.cpp` 560). Audit static-initialiser assumptions: modules were loaded into fresh bss on GC.
6. **Link**: implement nothing yet; make the port layer export every missing SDK symbol as a stub that
   logs `UNIMPLEMENTED <name>` and aborts (or returns 0 where the game tolerates it). The list of stubs
   hit at runtime is the Phase 1 to-do list — commit it as `xbox/docs/sdk-symbols.md`.
7. **Run**: `./xbox/build/host/re4_host --data /nonexistent` must print the game's early `OSReport`s
   (e.g. "RESET_KEEP_WORK memory clear...") and stop at the DVD layer.

## Acceptance

- Clean build on Ubuntu 22.04+ with `clang`, `gcc-multilib`, `libsdl2-dev:i386`, `libgl-dev:i386`
  (document the apt line in `xbox/README.md`).
- No edits under `src/` or `include/` except those unavoidable, each guarded by `#ifdef RE4_PORT` and
  tagged `// XBOX:`; list them in the PR description.
- `xbox/docs/sdk-symbols.md` lists every SDK symbol the link needed, grouped by subsystem, with a one-line
  note on how the port will implement each.
